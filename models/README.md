# AI Model Weights Directory

Place your ONNX model weight files directly in this folder or in `realtime_faceswap/models/`.

## Required Models:
1. **`scrfd_10g_bnkps.onnx`** (~16.5 MB)
   - Auto-download: Run `.\download_models.ps1`
   - Manual download link: `https://huggingface.co/MonsterMMORPG/tools/resolve/main/scrfd_10g_bnkps.onnx`

2. **`inswapper_128.onnx`** (~529 MB)
   - Auto-download: Run `.\download_models.ps1`
   - Manual download link: `https://huggingface.co/ezioruan/inswapper_128.onnx/resolve/main/inswapper_128.onnx`
